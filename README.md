# 🤖 SmartTalk AI

An AI-powered chatbot built with **React**, **Vite**, **Tailwind CSS**, and **Google Gemini API**. SmartTalk AI delivers fast, interactive conversations with a modern UI, persistent chat history, Markdown support, and a smooth typing animation for a realistic chat experience.

# ✨ Features

* 💬 AI-powered conversations using Google Gemini API
* 📝 Markdown rendering support
* 💾 Persistent chat history with LocalStorage
* 📂 Recent chats sidebar
* 🔄 Start a new conversation anytime
* 📋 One-click copy response
* ⌨️ Smooth typing animation effect
* 📜 Auto-scroll to latest messages
* 📱 Fully responsive design

# ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd smarttalk-ai
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
